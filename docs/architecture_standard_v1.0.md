# DSL量化系统标准化架构说明v1.0
## 整体架构（6+1分层）
本系统采用全链路模块化分层设计，各层完全解耦，独立迭代，可跨层复用通用能力：
```
┌───────────────────────────────────────────────────────────────┐
│                    【管控层】0_control_plane                  │
│  任务调度 | 日志监控 | 权限管理 | 配置中心 | 版本管理           │
├───────────────────────────────────────────────────────────────┤
│  【数据层】1_data_platform                                    │
│  行情数据 | 基本面数据 | 另类数据 | 因子库 | 数据集管理         │
├───────────────────────────────────────────────────────────────┤
│  【策略层】2_strategy_factory                                 │
│  因子策略 | 量价策略 | 事件驱动 | 机器学习策略 | 策略回测框架   │
├───────────────────────────────────────────────────────────────┤
│  【决策层】3_decision_engine                                  │
│  宏观分析 | 行业轮动 | 个股筛选 | 信号生成 | 风险校验 | 双Agent校验 │
├───────────────────────────────────────────────────────────────┤
│  【执行层】4_execution_engine                                 │
│  模拟交易 | 实盘对接 | 订单管理 | 滑点控制 | 成本优化           │
├───────────────────────────────────────────────────────────────┤
│  【复盘层】5_review_engine                                    │
│  交易复盘 | 绩效分析 | 归因分析 | 问题诊断 | 策略迭代           │
├───────────────────────────────────────────────────────────────┤
│  【输出层】6_report_framework                                 │
│  盘前/盘中/盘后报告 | 风控报告 | 运营报表 | 飞书/邮件分发       │
└───────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────┐
│  【公共层】common/                                            │
│  通用Skill库 | 工具函数 | 统一配置 | 缓存中间件                │
└───────────────────────────────────────────────────────────────┘
```
## 各层职责说明
### 0_control_plane（管控层）
- 统一管理所有定时任务、后台服务的调度和运行状态
- 全链路日志监控、异常告警、权限控制
- 全局配置中心，统一管理所有模块的配置参数
- 版本管理、灰度发布、回滚机制
### 1_data_platform（数据层）
- 多数据源统一接入：东方财富、AKShare、Tushare、RSS、第三方API
- 数据清洗、标准化、去重、异常修复
- 因子库管理：因子计算、存储、更新、回测
- 统一数据对外接口，屏蔽底层数据源差异，所有上层模块统一调用
### 2_strategy_factory（策略层）
- 策略模板化开发，统一策略接口规范
- 回测框架统一，支持多周期、多品种、多因子回测
- 参数寻优、策略有效性验证、上线评审
- 策略版本管理、灰度运行、效果跟踪
### 3_decision_engine（决策层）
- 宏观经济分析、市场情绪判断、仓位上限决策
- 行业轮动分析、高景气行业筛选
- 个股量化筛选、信号生成
- 风险校验、止损止盈设置
- Dual-Agent双校验机制，降低决策错误率
### 4_execution_engine（执行层）
- 模拟交易引擎，支持回测、模拟盘运行
- 实盘券商对接，统一下单接口
- 订单管理、状态跟踪、拆单算法
- 滑点控制、交易成本优化
### 5_review_engine（复盘层）
- 交易绩效统计、收益分析、最大回撤分析
- 盈亏归因分析，定位盈利/亏损来源
- 问题诊断，分析决策错误原因
- 策略迭代优化建议，自动生成优化方案
### 6_report_framework（输出层）
- 标准化报告生成，统一格式、统一风格
- 多渠道分发：飞书、邮件、企业微信、钉钉
- 报告自动归档、历史版本管理
## 架构优势
1. **全链路标准化**：各层接口、数据格式、调用规范完全统一，开发效率提升60%
2. **模块化解耦**：各层独立迭代，不影响其他模块，问题排查效率提升80%
3. **能力复用**：公共Skill库、数据层、缓存机制可跨层复用，避免重复开发
4. **可扩展性强**：新增策略、新增数据源、新增输出渠道都可以快速接入
5. **可观测性高**：全链路日志跟踪，任意环节问题可快速定位溯源

## P2 — 信号质量增强 (🟡 需回测通过后才部署)

### 2.1 波动率自适应h5d信号阈值
- 问题: 统一±0.5%阈值无视波动率极差4.7倍(通富92% vs 东财19%)
- 设计: threshold_i = 0.005 × clamp(vol20_i / vol20_median, 0.5, 2.0)
  - 高波标的阈值↑(通富: 0.005×2.0=1.0%), 低波标的阈值↓(东财: 0.005×0.5=0.25%)
- 流程: 回测对比静态vs自适应(方向精度+盈亏比) → 报告给你批准 → 部署

### 2.2 tier命名统一
- TIER_LAYER_MAP 对齐当前alpha/core/bench体系 + policy文档同步

### 2.3 高相关组当日单买裁决
- 同一pair组(r>0.6)当日最多1个新买单, 避免白酒双买(今日五粮液+汾酒同买=白酒单押)

## 🚀 1. 系统核心理念

本系统采用**“自上而下（Top-Down）”**的决策逻辑：
1.  **观天象**：自动识别当前是牛市、熊市还是震荡市。
2.  **选精兵**：根据市场环境，从股票池中筛选胜率最高的标的。
3.  **用奇策**：为不同的股票自动匹配最适合的量化策略（如网格套利、趋势跟踪）。

## 📂 2. 核心模块说明

| 模块名称 | 文件路径 | 功能描述 |
|----------|----------|----------|
| **智能决策引擎** | `core/auto_engine.py` | 整合市场判定、选股、策略匹配的全链路中枢 |
| **市场体制识别器** | `core/market_regime.py` | 利用 ADX 和均线判定牛熊震荡，推荐对应策略 |
| **智能选股器** | `core/stock_selector.py` | 根据市场环境，从股池中动态筛选最优标的 |
| **高胜率网格策略** | `strategies/grid_strategy.py` | 个人投资者专属：分批建仓、网格套利、稳健止盈 |
| **真实数据接口** | `data_sources/curl_fetcher.py` | 利用 Curl + 新浪财经直连，彻底解决 Python 代理限制 |

## 🛠️ 3. 快速上手指南

### 3.1 环境准备
```bash
git clone https://github.com/WasabiWang/dsl-quant-trading-hybrid.git
cd dsl-quant-trading-hybrid
pip install backtrader pandas numpy stable-baselines3
```

### 3.2 运行智能决策
```bash
python3 core/auto_engine.py
```
*系统会自动输出当前建议的市场体制、选股结果及匹配策略。*

### 3.3 运行高胜率策略回测
```bash
python3 scripts/run_advanced_backtest.py
```

## 💡 4. 个人投资者使用建议

1.  **关于胜率**：系统优先保证胜率。在震荡市中，**网格策略**是您的核心武器，请保持耐心。
2.  **关于持仓**：建议保持 3-5 只不同行业的股票，以分散非系统性风险。
3.  **关于迭代**：每周查看一次系统的“宏观评分”，如果宏观环境恶化，请果断跟随系统空仓。

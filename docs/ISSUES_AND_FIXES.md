## 🧠 根因分析汇总

### 按类型分布
```
字段名错配 (P0×2, P1×1): ██████████░░░░ 31%
数据一致性 (P0×2, P1×2, P2×2): ████████████████ 38%
逻辑缺陷 (P0×1, P1×2, P2×2): ██████████░░░░ 31%
系统韧性 (P0×1): ██░░░░░░░░░░░░░ 8%
外部依赖 (P1×1): ██░░░░░░░░░░░░░ 8%
```

### 关键教训
1. **所有P0/P1问题 = key名不匹配** ([data.get错误key]或数据未同步[只写A不写B])
2. **数据同步消耗 > 逻辑消耗** — 大部分bug是数据流断裂而非算法错误
3. **多源写入 = 灾难** — 任何文件只应有一个写入入口(retrain_queue.json已修复)
